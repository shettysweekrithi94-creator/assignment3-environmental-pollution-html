# Assignment 3 – Environmental Pollution (Image Map)

This project is created as part of Assignment 3 for learning HTML image maps and basic web page structuring.

## Description
The web page explains different types of environmental pollution using an image map. Specific areas of the image are clickable and redirect the user to related information. The assignment demonstrates the use of HTML image mapping concepts.

## Features
- HTML image map using `<map>` and `<area>` tags
- Clickable regions on an image
- Use of images with proper attributes
- Simple and structured HTML layout

## Technologies Used
- HTML
- Image Map
